# 🚛 Truck Dispatch Pro- Professional Truck Dispatching Platform

![Website Preview](https://images.unsplash.com/photo-1583212292454-1fe6229603b7?w=1000&h=400&fit=crop)

## 📌 Overview

**Truck Dispatch Pro** is a complete, modern, and fully responsive website for truck dispatching services. It helps owner-operators and fleet owners connect with dispatchers, find loads, track earnings, and manage their trucking business efficiently.

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🏠 **10+ Professional Pages** | Home, About, Services, Pricing, Contact, Register, Login, Dashboard, Welcome |
| 🤖 **AI Chatbot** | 24/7 virtual assistant for driver support |
| 📊 **AI Load Rate Predictor** | Predicts rates per mile based on origin, destination, and truck type |
| 🗺️ **AI Route Optimizer** | Smart route planning with fuel cost calculation |
| 👤 **Driver Dashboard** | Personal dashboard with load tracking and payment history |
| 🌓 **Dark/Light Mode** | User preference saved in localStorage |
| 📱 **Fully Responsive** | Works on mobile, tablet, and desktop |
| 📧 **Newsletter Subscription** | Email subscription with localStorage |
| 🍪 **Cookie Consent** | GDPR compliant cookie popup |
| 💬 **Floating Buttons** | Quick call and email access |
| 🎬 **Animated Background** | Moving truck, floating icons, and particles |

## 🤖 AI Features Explained

### 1. AI Chatbot
- 24/7 virtual assistant
- Answers questions about rates, registration, pricing
- Quick action buttons for common queries

### 2. AI Load Rate Predictor
- Predicts rates per mile based on:
  - Origin & Destination cities
  - Truck type (Dry Van, Reefer, Flatbed, Hot Shot)
  - Distance in miles
- Displays confidence score

### 3. AI Route Optimizer
- Calculates optimal routes between cities
- Estimates fuel costs based on MPG and fuel price
- Shows estimated driving time
